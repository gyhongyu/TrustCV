## 1. 系統願景與核心定位

**TrustCV** 定位為新一代**高可信度專業人力顧問中介平台**。不同於傳統求職網站僅做單向刊登與被動媒合，TrustCV 秉持「對求職者與雇主雙向負責」的中立顧問立場，建立嚴格的雙向把關與考問防線：

1. **對雇主端的真實度與信用把關（KYC 與反向拷問）**：  
   * 拒絕來路不明或條件惡劣的職缺。所有職缺刊登必須先通過大模型企業調查（KYC 報告）與顧問團隊人工審核，並針對模糊 JD 進行反向考問與透明度評級。  
2. **對候選人的適配度與資歷深挖（憑證驗證與 AI 初面）**：  
   * 跳過誇大不實的文字履歷，透過真實證件重構客觀時間線，並針對資格缺口與技能短板進行主動考問。  
3. **對顧問與 HR 審查效率的極致提升**：  
   * 提供「職涯時間線為先、AI 拷問紀錄在後、原始履歷放最後」的高效決策報告，大幅縮短人工篩選時間。

## 3. 管線階段詳細規格

### Stage 1: 雇主企業背景 KYC、人工審核防線與職缺反向考問 (Employer Pipeline)

作為專業人力顧問平台，並非所有企業付費即可發布職缺，必須通過嚴格的准入審查。

#### 1.1 大模型企業背景 KYC 與風險調查 (Company KYC Profiling)
當企業端註冊並提交統編、營業登記、企業名稱與初步職缺時，系統調用大模型檢索與評估企業信譽，生成「企業 KYC 與勞動合規評估報告」：
* **企業基本面核實**：營業登記狀態、資本額、設立年限、董監事背景。  
* **勞動法遵與訴訟檢核**：歷史勞資糾紛、勞檢違規裁罰紀錄、未依法提撥退休金或加保紀錄。  
* **輿情與雇主品牌風評**：社群與求職論壇上的負面爆料、離職率與加班文化標籤。  
* **大模型 KYC 風險等級評定**：自動輸出評級（低風險 / 中度疑慮 / 高風險警告），並條列關鍵風險事實。

#### 1.2 人力顧問人工審核閥門 (Manual Headhunter Gatekeeper)
此階段為系統剛性防線，未經審核的職缺一律處於草稿封閉狀態：
* **審核通過（Approve）**：企業信用良好、資訊真實，准予進入下一步職缺解析並於平台曝光。  
* **要求補件/修正（Revise）**：存在中度疑慮（例如：無勞健保說明、薪資明顯低於市場水準），顧問退回並附帶整改要求。  
* **直接駁回（Reject）**：被判定為高風險、虛假招聘、吸金或嚴重違反勞動法令之企業，平台直接拒絕受理並列入黑名單。

#### 1.3 職缺結構化解析與反向考問 (JD Reverse Interrogation)
通過審核的企業，大模型對其發布的具體職缺描述（JD）與任職要求（JR）進行解析：
* **提取維度**：  
  * 硬性門檻：學歷階層、科系偏好、必要法定證照、最低從業年資。  
  * 核心專業能力：技術工具、框架、專案實務要求。  
  * 軟實力與隱性環境：跨部門溝通、團隊協作、抗壓適應力。  
* **權重自動配置**：  
  * 大模型依職位層級自動分配總合為百分之百的各項指標權重（例如：資深架構師職位，技術實務權重設定為 45%，學歷權重設定為 10%）。  
* **職缺透明度反向考問機制**：  
  * 若企業將薪資標示為模糊的「面議」，或未清楚列出工時、輪班、加班津貼與法定福利，系統會直接提示發布者進行補全。  
  * 企業若堅持不補全，該職缺將獲得較低的「JD 透明度星級評分」（1 至 5 星），此評級直接對候選人公開，揭露求職風險。

### Stage 2: 候選人真實憑證與職涯時間線重構 (Candidate Pipeline)

#### 2.1 原始客觀證件驗證提取
候選人免除傳統重複填寫各類格式履歷的痛點，改為上傳客觀事實憑證：
* 學歷證書、學位認證證明  
* 歷任公司在職證明、離職證明或官方勞保投保明細  
* 專業技術證照、考試成績單  
* 具體作品集、技術專案或程式碼公開庫連結

#### 2.2 職涯時間線生成引擎 (Career Timeline Engine)
大模型將驗證後的證件轉化為連續的時間序列軌跡：
* **人生學習與就業節點**：精確標註求學起止、主修學位、歷任雇主、任職週期與職稱變更。  
* **異常點與疑點標註**：  
  * 自動偵測超過特定月數的「經歷空窗期」。  
  * 標註兩份工作之間重疊的「時間重疊衝突」。  
  * 標註無任何公證文件佐證的「口頭自述任職項目」。

---

### Stage 3: 匹配交集與落差比對 (Gap Analysis Pipeline)

當候選人點擊投遞時，系統將 Stage 1 通過審核的職缺需求矩陣與 Stage 2 的候選人真實時間線進行比對，自動劃分三類項目：
1. **完全符合項**：年資完全滿足、具備官方指定證書、學歷符合規範。  
2. **待舉證自述項**：候選人聲稱擁有該項能力，但未附帶第三方證照或機構認證。  
3. **客觀未達標項**：職缺要求碩士學位而候選人僅有學士學位；或職缺要求五年年資而候選人僅滿三年。

---

### Stage 4: AI 初試智慧考問互動 (Interactive Probing Pipeline)

系統扮演公正且專業的中介顧問面試官角色，針對 Stage 3 檢驗出的缺口與疑點，向候選人發起追問。

#### 4.1 考問策略與邏輯矩陣

| 缺口類型 | AI 考問提問策略 | 期望候選人反饋 |
| :--- | :--- | :--- |
| **硬性門檻不足**（例：缺少要求之碩士學位） | **動機與替代實力考問**：「本職位設定碩士學位為優先條件，您的客觀時間線顯示為學士學歷。請具體說明您在實務專案中的哪些核心成果或自學深度，足以說服雇主與顧問破格推薦？」 | 提出量化專案成果數據、技術突破或領導歷練事實。 |
| **關鍵技能無官方認證**（例：自述精通高併發架構但無證照） | **深度實務情境題（Scenario Probing）**：「您未附上該項目的相關認證。請詳細陳述您在上一任職專案中，如何設計該系統架構？曾遭遇何種效能瓶頸，又是透過何種具體方案進行調優？」 | 具體闡述架構思路、技術選型理由與前後成效指標對比。 |
| **時間線異常或長期空窗**（例：長達一年無在職紀錄） | **職涯延續性與狀態考問**：「時間線顯示您在該年度存在長達十二個月的經歷空窗，這段期間您是否進行了技能培訓、接案專案或自主創業？請具體說明。」 | 提供進修認證、獨立作品展示或合情合理的個人規劃闡述。 |

#### 4.2 候選人應對狀態分支
* **充分舉證**：候選人邏輯嚴密且提出具體數據佐證，系統給予實質替代肯定。  
* **回答模糊**：候選人僅以籠統概念帶過、無法回答細節，系統記錄為「實務深度存疑」。  
* **主動放棄或未回應**：候選人跳過該問題，系統強制記錄為「候選人未回應此項目質疑」，該項以零分計算並啟動懲罰性扣分。

---

### Stage 5: 多維度動態計分規則 (Scoring Engine)

系統採透明且嚴謹的業務權重打分法：
1. **基礎分計算**：  
   * 每一項 JD 需求指標均依 Stage 1 賦予的百分比權重計算。  
   * 若候選人證件完全符合，該項取得滿分 100 分。  
   * 若存在缺口，則依據 Stage 4 候選人在 AI 考問中的回答品質，由大模型評定等效實力分數（0 至 100 分之間）。  
2. **加權總分產出**：  
   * 將各指標的得分乘以對應權重百分比後相加，得出基礎適配總分。  
3. **違規與迴避懲罰**：  
   * 若候選人對關鍵核心缺口選擇迴避或未作答，系統直接在加權總分中額外扣除固定懲罰分。  
4. **排序與分級標準**：  
   * 最終結算出百分制「綜合適配評分」，並劃分為：
     - **極力推薦**：85 分以上
     - **具備潛力**：70 至 84 分
     - **不建議推薦**：70 分以下

### Stage 6: 顧問與 HR 決策審查報告結構 (Report Output Specification)

產出之審查報告採三層階梯式排版，讓企業 HR 與內部中介顧問在半分鐘內完成決策判斷：

```text
+-------------------------------------------------------+
|  【第一層】個人職涯時間線全景 (Timeline Overview)       |
|  - 視覺化生命週期軌跡 (學歷 -> 歷任職務 -> 空窗/重疊標註) |
|  - 經客觀證件比對認證之真實年資與在任狀態              |
+-------------------------------------------------------+
|  【第二層】AI 考問實錄與推薦評分 (Probing & Score)     |
|  - 綜合適配分數 (例: 88分 / 極力推薦)                  |
|  - 缺口深度考問對話完整實錄 (問題、候選人答覆、AI 專家點評)|
|  - 待查疑點與風險標籤 (例: 曾迴避特定技術問題)         |
+-------------------------------------------------------+
|  【第三層】候選人自述履歷與原始附件 (Raw Attachments)   |
|  - 候選人提交之文字自述版履歷原文 (折疊收合顯示)       |
|  - 原始畢業證書、在職/離職證明、證照掃描檔備查          |
+-------------------------------------------------------+
```

## 4. 系統 API 與資料庫狀態流轉（State Machine）

```text
[企業提交資訊與職缺]   
       │  
       ▼  
[KYC_Processing] (大模型生成企業背景與風險報告)  
       │  
       ▼  
[Consultant_Auditing] (中介顧問人工審核准入防線)  
       ├─── (不合規) ───► [Job_Rejected] (終止發布，列入紀錄)  
       │  
       ▼ (通過審核)  
[Job_Published] (職缺發布，附帶透明度星級)  
       │  
       ▼  
[Candidate_Applied] (求職者提交證件與投遞申請)  
       │  
       ▼  
[Timeline_Constructed] (證件比對完成，建立時間線軌跡)  
       │  
       ▼  
[Gap_Probing] (比對 JD 權重，AI 面試官啟動雙向考問)  
       │  
       ▼  
[Scored_And_Ranked] (計算動態加權總分與扣分)  
       │  
       ▼  
[Report_Delivered] (產出標準三層審查報告，交付 HR 與顧問決策)
```

## 5. 核心中介顧問價值總結

1. **對求職者**：  
   * 杜絕黑心企業與詐騙風險，所有上架職缺均經過大模型背景調查與顧問人工審核。  
   * 非典型背景或硬性條件未滿的求職者，能透過 AI 考問環節以實務經驗與專案成果為自己爭取機會，不再被傳統履歷第一關機械式淘汰。  
2. **對招聘企業與 HR**：  
   * 省去數十小時比對文字包裝與面試無效溝通的時間。  
   * 時間線一眼看穿跳槽頻率與真實年資；AI 考問紀錄直接檢驗真才實學，精準篩選出高契合度人才。  
3. **對 TrustCV 平台品牌**：  
   * 樹立專業、嚴謹、負責任的高端人力顧問中介形象，透過雙向真實度考核打造最具信任度的求職招聘生態系。
