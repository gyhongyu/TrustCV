# ADR 002: 投遞快照提存與個人資料主權保障 (Submission Snapshot & Escrow)

> **狀態**: 已定案 (Accepted)  
> **日期**: 2026-09-28  
> **背景**: 解決用戶個人 Google Drive 檔案後續遭修改、刪除或隱藏，導致官方驗證憑證與企業推薦檔案失效的商業風險。

---

## 1. 核心商業與技術矛盾

1. **個人資料主權**：平時用戶對自己 Google Drive 內的檔案與個人履歷擁有完全修改、刪除、隱藏的權限。
2. **審核真實性與防賴帳**：一旦用戶應聘特定職缺，管理員核驗並推薦給台灣雇主後，該筆投遞的佐證與內容必須不可篡改。

---

## 2. 解決方案：投遞快照提存機制 (Escrow Snapshot)

* **觸發點**：僅在用戶於職缺頁面點擊 **【應聘/投遞】(Apply)** 的瞬間觸發。
* **執行流程**：
  1. **公開條目篩選**：系統僅讀取當前履歷中狀態為 **公開 (Public)** 的項目，隱藏 (Private) 項目不被提取。
  2. **Drive 原件複製提存**：
     * 呼叫 Google Drive API 的 `Files.copy`，將公開項目對應之原件（大頭照、離職證明、Form 16、Aadhaar/PAN 等），秒級複製一份至「TrustCV 官方審核存檔目錄」。
  3. **履歷快照凍結**：
     * 將當前履歷數據結構封裝為不可變快照（Snapshot JSON / MD）。
  4. **中央台帳指紋註冊**：
     * 將快照 ID 與 SHA-256 雜湊登記於 TrustCV 官方 Sheets/資料庫之 `Applications` 資料表。

---

## 3. 效益與邊界

* **零拘束**：用戶隨後在個人 Drive 中刪除、更名或修改經歷，**100% 不影響已送出的官方審核存檔**。
* **免除鎖定狀態**：用戶感受不到被第三方系統剝奪修改權，兼顧個人隱私與商業閉環。
